PaperMosaic

Privacy Policy

Last updated: 13 August 2026
Important information. This policy describes the current repository implementation. It is not formal legal advice; have a qualified lawyer review it for the jurisdictions in which you operate.

PaperMosaic is a browser-based PDF toolkit operated through https://ilovepdf.vossgraves.cyou/ and its open-source repository. This policy explains what information the application handles, where it goes, and what choices users have.

1. Files processed in the browser

For the PDF editing and conversion operations implemented in this repository, files are loaded into the user’s browser and processed there. PaperMosaic does not intentionally upload those files to a PaperMosaic application server. Files may remain temporarily in browser memory while a tool is open and are released when the page or modal is closed, subject to the browser’s own behavior.

2. Information stored on the device

The application uses browser localStorage for limited, device-local state. The current implementation stores theme preference, anonymous per-device processing counters, and—in the AI Summariser settings—the user-provided OpenAI-compatible endpoint, model name, and API key. These values are not sent to PaperMosaic’s server by this client-only application. Do not save a key in a shared or untrusted browser profile; anyone with access to that profile may be able to inspect local storage.

3. Optional third-party requests

Some tools make network requests only when the user chooses the relevant feature. The AI Summariser sends extracted PDF text and the user’s configured authorization header to the endpoint the user enters, such as an OpenAI-compatible provider. Translate PDF sends text and language parameters to MyMemory’s translation API. Office conversion may download conversion engine assets from public package or hosting URLs. The application also loads font and icon assets from Google Fonts and cdnjs. Those providers process requests under their own terms and privacy policies; users should review them before using optional features.

4. Analytics, advertising, and cookies

The current repository does not intentionally include an analytics SDK, advertising tracker, or application cookie. The hosting provider, CDN, or security layer used to publish the site may create technical logs or cookies outside this repository. Configure and disclose those services separately if they are enabled in production.

5. Information PaperMosaic receives

PaperMosaic does not require an account for the browser tools and does not intentionally collect names, email addresses, PDF contents, or payment information through the current client-only implementation. If you contact the maintainers through GitHub, GitHub will process the information associated with that interaction under GitHub’s own policies.

6. Your choices

You can remove device-local PaperMosaic data through your browser’s site-data or local-storage controls. You can avoid optional AI and translation features if you do not want text sent to the selected provider. You can also use the core local-processing tools without entering an API key. Clearing site data may remove local settings and counters.

7. Children and legal compliance

PaperMosaic is a general-purpose utility and is not directed at children. Users are responsible for ensuring that their use of the tools complies with applicable privacy, confidentiality, copyright, export-control, and other laws. Do not process documents when you lack permission to do so.

8. Changes and contact

This policy may be updated when the application or its deployment changes. The version published at this URL is the current version. For privacy questions or requests, contact the operator using the public name Voss Graves at primevideoistaken@gmail.com. This is a public contact identity and does not state that Voss Graves is a registered legal entity. For non-sensitive project questions, the repository is available at github.com/vossgraves/iLovePDFs; do not post confidential personal information in a public issue.
